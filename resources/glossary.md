# Compact glossary

**API:** public interface through which other code invokes a component.  
**Artifact:** a saved result such as a JSON report or model file.  
**Baseline/monitor:** earlier and later seismic surveys in a time-lapse setting.  
**CI:** continuous integration: automatic checks on commits or pull requests.  
**Cross-validation:** repeated training/evaluation splits designed to estimate generalization.  
**Data leakage:** information enters training or preprocessing that would not be available when predicting genuinely unseen cases.  
**Editable install:** package installation that uses your current source tree (`pip install -e .`).  
**Feature:** model input variable.  
**Generative AI:** model that produces text/code or other content; output must still be validated.  
**GroupKFold:** scikit-learn split that keeps each group in one partition per fold.  
**Lag:** relative offset between signals, measured here in samples or seconds.  
**Macro F1:** unweighted average of per-class F1 scores.  
**Package:** importable collection of modules with an intentional interface.  
**Pipeline:** ordered transformations and estimation steps composed and fit together.  
**PR:** pull request: proposed code change subjected to review.  
**Ricker wavelet:** symmetric analytic waveform commonly used in synthetic seismic examples.  
**Streamlit:** Python framework for browser-based data interfaces.  
**Unit test:** repeatable assertion about a small component's behavior.  
**Validation group:** a set of correlated samples kept together during data splitting.
