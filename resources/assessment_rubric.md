# Assessment rubric

## Weekly challenge (20 points each)

| Dimension | Points | Description |
|---|---:|---|
| Correct behavior | 8 | Required numerical or structural result, including units and sign |
| Input/edge validation | 4 | Invalid shape, missing values, boundary conditions |
| Automated tests | 4 | New tests and passing exercise test |
| Code readability | 2 | Naming, type hints, documentation, maintainable structure |
| Engineering explanation | 2 | Rationale, failure mode, assumptions and limitations |

## Final capstone (100 points)

| Dimension | Points |
|---|---:|
| Numerical correctness and tests | 25 |
| Architecture and code quality | 20 |
| Leakage-aware ML design and metrics | 20 |
| AI-assisted workflow with human verification | 15 |
| Reproducibility and documentation | 10 |
| Clear engineering handoff | 10 |

**Interpretation:** 85–100 = strong demonstration, 70–84 = adequate with improvements needed, 50–69 = incomplete core elements, below 50 = significant gaps. These bands are course guidance, not a formal certification. A flawed or unsafe data-sharing practice must be corrected regardless of score.
