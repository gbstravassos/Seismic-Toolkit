# Reference solutions — open after attempting each challenge

`reference_challenges.py` contains **one possible solution** for each weekly challenge in `seismic_toolkit/challenges.py`. You can run the solution tests separately with:

```bash
python -m pytest tests/test_reference_solutions.py -q
```

Avoid copying the answers immediately: attempt the spec, write a failing test, implement your solution, compare results, and only then inspect the reference.
